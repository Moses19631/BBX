# Beyblade X Deck Manager

App web per tenere inventario, deck da 3 bey, win rate e finish (Burst / Xtreme / Pocket) dei tuoi Beyblade X.

## Come si usa dal telefono
Apri il link della pagina nel browser del telefono.
- Android (Chrome): menu ⋮ → "Aggiungi a schermata Home"
- iPhone (Safari): pulsante Condividi → "Aggiungi alla schermata Home"

## Dove sono i dati
I dati restano solo nel browser di quel telefono. Non c'è un account né un server.
Per non perderli usa la scheda **💾 Backup**: scarica il file `.json` e conservalo.
Per spostarli su un altro telefono, importa lo stesso file.

## Attenzione
- Cancellare i dati del browser o disinstallarlo cancella anche i bey: fai un backup ogni tanto.
- L'importazione sostituisce i dati attuali sul telefono.

## Database parti
Lame, ratchet e bit tratti da beybladehub.app. Le parti mancanti si possono aggiungere con "Aggiungi … personalizzato".

## File
- `index.html` — l'app completa (un solo file, nessuna dipendenza esterna)
- `manifest.json` — permette di installarla come app
